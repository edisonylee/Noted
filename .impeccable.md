# noted — design context

## Users and product

Noted is a local-first personal context system for a person's notes, meetings,
calendar, journal, people, and future sources. It should make capture quick and
returning to original context easy. Preserve the current shared Team workspace, messages, permissions, and the separate Documents and Library views when applying visual changes. PRODUCT_STRATEGY.md remains authoritative
for positioning and capabilities.

## Selected direction

The selected direction is **Soft Cut + monochrome + interchangeable neon**.
The user retained the Noted name and selected the compact, softly squared
lowercase wordmark. The subsequent font/name alternatives were not selected.
The approved brand board is in docs/brand/gravity-of-a-thought/brand-exploration-v1.png.

This supersedes the earlier warm off-white/clay preference for new design work.
The Mac application now uses this foundation through its built-in neon packs.
Existing custom themes remain supported alternatives; the default is citron.

## Aesthetic

- White and near-black foundations, neutral grays, thin separators, ample reading space.
- One vivid accent with interchangeable citron, electric blue, hot pink, and acid green palettes.
- Bright fill, readable accent text, subtle selection, and focus are separate roles.
- Geist for product text; Soft Cut artwork for the brand wordmark.
- Lucide icons, no emoji-as-icons. Clear type and spacing provide hierarchy.
- The orbital archive and connecting thread support expressive brand moments.
  Keep reading surfaces focused on the user's content.
- Fast, restrained transitions; respect reduced motion. No decorative glow or gradients.

## Principles

1. Quiet by default, expressive when useful. Let notes and their sources lead.
2. Make accent color meaningful: capture, selection, a key thought, or its source.
3. Keep text readable in every palette and mode. Bright neon needs a companion
   shade for text and focus on white; use dark text on neon fills.
4. Use whitespace and separators before adding more containers.
5. Keep source context accessible on demand, with a usable narrow-screen path.
6. Retain custom themes and keep functional status semantics independent of accent.

## Implementation reference

The first reusable foundation lives in src/design-system/. See
[the guide](docs/design-system/README.md) for exact tokens, components, preview,
contrast checks, and migration boundaries. The preview remains an isolated local fixture surface. The production layer
is src/design-system/product.css, loaded by the Mac entry point and scoped to
neon themes. Native iOS has a separate shell.
