# Gravity of a Thought — brand exploration

The selected campaign reference expands Noted's Soft Cut identity through
grayscale photographic archives, impossible orbital scale, and a connecting
neon citron thread. This is a brand exploration, not final artwork or an
implemented product interface.

## Assets

- `brand-exploration-v1.png`: six-part brand application board.
- `campaign-reference.png`: the exact campaign image selected by the user.
- `brand-board-template.png`: user-provided presentation structure reference.
- `next-logo-exploration-template.png`: user-provided reference reserved for the
  next logo exploration round; not used to change the current logo.

## Generation brief

Produced with the built-in image generation tool. Expand the selected campaign
into one cohesive two-column, three-row presentation using the supplied brand
board template and existing Soft Cut wordmark. Show a black cloth notebook with
citron elastic instead of the watch, the orbital campaign hero, three portrait
posters, four palette swatches, matte stationery, and a sparse desktop app brand
application. Keep grayscale photographic fragments and the citron connecting
thread consistent across the applications. Preserve the existing wordmark and
monogram; defer logo exploration until the next round.

The proposed palette labels are #0A0A0A, #FFFFFF, #DFFF00, and #D9D9D9.
Raster rendering is illustrative and does not define exact production colors.
Copy, app chrome, navigation, and layout remain concept material, not approved
product specifications. The board is a visual reference rather than editable
print artwork or vector logo files.
